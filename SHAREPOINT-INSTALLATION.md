# Ersatt av privat OneDrive

Den tidigare organisationsanslutningen till SharePoint används inte i denna version.

Följ **ONEDRIVE-INSTALLATION.md** i samma paket. Kör migrering 0037 efter 0036 och anslut det privata Microsoft-kontot via Administratörsverktyg → Säkerhetskopiering → Anslut OneDrive.

Gamla SharePoint-kopior flyttas inte automatiskt. Filval, intervall och övriga funktioner bevaras.
